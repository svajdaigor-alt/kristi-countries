# Kristi · Cesta kolem světa

Jednoduchá česká výuková hra podle dodaných učebnicových stran. Dva režimy: vlajky (12 otázek, čtyři anglické možnosti) a země/národnosti (24 otázek, každá dvojice v obou směrech). Náhodné pořadí, bodování a opakování chyb po každém kole. Turkey odpovídá učebnici; the UK/British a the USA/American.

Hra: https://svajdaigor-alt.github.io/kristi-countries/

Na iPhonu otevřete v Safari → Sdílet → Přidat na plochu. Po prvním úplném načtení funguje také offline. Žádné účty ani sledování.

Statické soubory bez závislostí a sestavování. GitHub Pages: main, kořen repozitáře. Lokálně lze spustit `python -m http.server 8000`.

Vlajky: flag-icons (MIT), https://github.com/lipis/flag-icons. Viz FLAGS-LICENSE.txt. Fotografie učebnice nejsou zveřejněné.
